# 第一题语义用例草稿：天幕之外

状态：人工预期草案；等待故事审定与 `docs/CONTRACTS.md` 的 case schema 后再映射成结构化数据。以下是标注预期，不是模型输出、实测结果或准确率。

## 暂定线索语义

用描述代替最终 clue ID，避免与契约或审题后的 ID 冲突：

- **投影来源**：室内天幕上的星图由投影仪产生。
- **可开屋顶**：观测站屋顶能够滑开/打开。
- **晴朗星空**：当晚室外天空晴朗，肉眼能看见真实星星。
- **因果关系**：讲解员关掉室内投影并打开屋顶，因此游客能看到真实夜空。仅提事实、时间先后或反向因果不命中此项。

“新增线索”均指本条玩家输入提供证据后可新增的线索；主持人答复、提示内容和标准答案内容均不能作为玩家证据。预期答案使用便于人工审查的自然语言标签，待契约确定后再映射到枚举。

## 人工复核要点

- 正例须同时检查判定与线索，不接受只给出正确主持人答复但漏记线索。
- P03/P04、R03/R04、S03/S04 检查近似内容、未交代事实和否定表达是否被误收。
- C03–C06 检查因果方向及因果缺项；即便相关事实已发现，也不能自动新增因果线索。
- X02 的唯一指代来自此前玩家自己的表达；X11/X12 检查主持人自己的话不会变成玩家证据。
- 这些案例只定义人工预期。当前没有真实模型调用，也没有模拟结果或准确率结论。
